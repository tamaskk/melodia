# Csatolmányok

Ide tedd a fájlokat, amiket minden kiküldött levélhez csatolni kell
(pl. `Kalman-Tamas-Krisztian-CV.pdf`, `ajanlolevel.pdf`).

- Minden itt lévő fájl felkerül a levélre, ábécésorrendben.
- Ez a `README.md` és a rejtett fájlok (`.` kezdetűek) kimaradnak.
- Nyelv szerint is szétválasztható: ha van `hu/` és/vagy `en/` almappa, akkor a
  gyökérben lévő fájlok mellé a kontakt nyelvének megfelelő almappa tartalma
  megy — így a magyar levélhez a magyar, az angolhoz az angol önéletrajz.
- Méretkorlát: összesen 20 MB (a Gmail 25 MB-nál elutasítja a levelet).

A mappa tartalma nincs verziókövetve — személyes dokumentumok.
